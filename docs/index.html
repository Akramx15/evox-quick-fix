Transparency and both Quick Search hooks remain locked to the exact verified SM-S918B/Quick Search setup. The folder hook repairs Quick Search external-storage containing-folder intents, including APK results, through DocumentsUI without changing any registered handler or default app. Circle independently requires Launcher3, Google contextual search, the contextual_search service and KernelSU. Magic Mount-rs is additionally required only when the ROM is missing the feature declaration.

Safe workflow

  1. Verify the release SHA-256 and install the signed APK.
  2. Read onboarding and Help. Grant root only after the diagnostics match.
  3. Apply one feature at a time. The Quick Search hooks intentionally switch to Home while Quick Search restarts; this is not a crash.
  4. For debloat, select up to five normal packages—or one dangerous package and type its exact ID.
  5. Test calls, messages, data, Wi-Fi, Bluetooth, camera, biometrics, alarms, Google notifications, Recents and Circle.

Recovery

The core restore and Debloat restore are deliberately separate. Debloat restores only ledger-owned packages to their original PackageManager state 0..4.

adb shell su -c 'sh /data/adb/evox-quick-fix/debloat-restore.sh'

Core module emergency disable:

adb shell su -c 'touch /data/adb/modules/evox_contextual_search_fix/disable; touch /data/adb/modules/evox_overview_transparency/disable; reboot'

FAQ

Does installing the beta disable 104 packages?

No. The initial selection is empty and every package displays Keep until you explicitly select it.

Why did the app send me to Home?

The Quick Search hooks must restart Quick Search. The tool stores the operation before doing so; reopen it for the result and restart prompt.

Does the APK-result fix install APKs automatically?

No. On the exact supported Quick Search build it repairs external-storage containing-folder actions, including APK results, through DocumentsUI without the invalid URI grant. It opens the folder, installs nothing, and changes no package handler or default app.

Why is a package marked External?

It was disabled before EvoX Quick Fix owned it. The restore action will not enable it.

Why is Circle available without Quick Search or Vector?

Circle checks Launcher3, Google contextual search, the system service and KernelSU independently. It checks Magic Mount-rs only when a systemless feature declaration is needed.

طريقة الاستخدام الآمنة

  1. تحقق من SHA-256 وثبت APK الموقع.
  2. اقرأ شاشة البداية وHelp، ولا تمنح Root إلا بعد تطابق الفحص.
  3. طبق خيارًا واحدًا كل مرة. ينقلك Hookا Quick Search إلى Home عمدًا أثناء إعادة تشغيل Quick Search؛ هذا ليس crash.
  4. للدبلوت: خمس حزم عادية كحد أقصى، أو حزمة خطرة واحدة مع كتابة Package ID.
  5. اختبر المكالمات والرسائل والبيانات والواي فاي والبلوتوث والكاميرا والبصمة والمنبه والإشعارات وRecents وCircle.

أسئلة شائعة

هل تثبيت beta يعطل 104 حزم؟

لا. التحديد يبدأ فارغًا وكل حزمة تظهر Keep حتى تختارها بنفسك.

لماذا نقلني التطبيق إلى Home؟

يحتاج Hookا Quick Search إلى إعادة تشغيل Quick Search. تحفظ الأداة العملية أولًا؛ افتحها مجددًا لرؤية النتيجة وطلب Restart.

هل يثبت إصلاح نتائج APK الملفات تلقائيًا؟

لا. في نسخة Quick Search المطابقة يصلح فتح مجلدات التخزين الخارجي المحتوية، ومنها نتائج APK، عبر DocumentsUI دون URI grant غير الصالح. يفتح المجلد ولا يثبت شيئًا ولا يغيّر Handler الحزم أو التطبيق الافتراضي.

لماذا تظهر حزمة External؟

كانت معطلة قبل أن تملكها الأداة، ولذلك لن يقوم الاسترجاع بتفعيلها.

لماذا Circle مستقل عن Quick Search وVector؟

يفحص Circle ‏Launcher3 ومزود Google وخدمة النظام وKernelSU بصورة مستقلة، ولا يفحص Magic Mount-rs إلا عند الحاجة لإضافة تعريف الميزة systemless.
