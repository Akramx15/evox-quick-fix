Transparency and both Quick Search hooks remain locked to the exact verified SM-S918B/Quick Search setup. The folder hook repairs Quick Search external-storage containing-folder intents, including APK results, through DocumentsUI without changing any registered handler or default app. Circle independently requires Launcher3, Google contextual search, the contextual_search service and KernelSU. Magic Mount-rs is additionally required only when the ROM is missing the feature declaration.

LE Audio 1.2 is guarded by the tested SM-S918B, Android 16, owner-user, KernelSU, audio-policy and Bluetooth configuration hashes. It restores simultaneous LC3 playback and headset-microphone input for the verified ROM; validation there does not establish a fix for every ROM, device or application.

OneBack is an optional v1.3.0-beta.1 Vector/libxposed API 102 hook scoped only to HeliBoard on Android 16. It runs inside HeliBoard—not system_server—and does not synthesize a Back event. App-specific Back handling can differ, so this is not a universal compatibility claim for every app.

Safe workflow

  1. Verify the release SHA-256 and install the signed APK.
  2. Read onboarding and Help. Grant root only after the diagnostics match.
  3. Apply one feature at a time. The Quick Search hooks intentionally switch to Home while Quick Search restarts; this is not a crash.
  4. Before enabling integrated OneBack, disable the standalone dev.oneback.ime module to avoid duplicate hooks. Use OneBack's dedicated enable/disable controls and built-in test.
  5. For debloat, select up to five normal packages—or one dangerous package and type its exact ID.
  6. Test calls, messages, data, Wi-Fi, Bluetooth, camera, biometrics, alarms, Google notifications, Recents and Circle. If enabled, also test LE Audio playback/microphone and OneBack's built-in check.

Recovery

The core restore, LE Audio, OneBack controls and Debloat restore are deliberately separate. LE Audio and OneBack are not included in “Apply the four fixes.” “Restore ROM behavior” does not disable OneBack; its own Disable action removes only this module's HeliBoard scope and leaves its Quick Search scope intact. LE Audio also has its own Disable action and requires a manual reboot. Debloat restores only ledger-owned packages to their original PackageManager state 0..4.

adb shell su -c 'sh /data/adb/evox-quick-fix/debloat-restore.sh'

Core module emergency disable:

adb shell su -c 'touch /data/adb/modules/evox_contextual_search_fix/disable; touch /data/adb/modules/evox_overview_transparency/disable; reboot'

FAQ

Does installing the beta disable 104 packages?

No. The initial selection is empty and every package displays Keep until you explicitly select it.

Why did the app send me to Home?

The Quick Search hooks must restart Quick Search. The tool stores the operation before doing so; reopen it for the result and restart prompt.

Does the APK-result fix install APKs automatically?

No. On the exact supported Quick Search build it repairs external-storage containing-folder actions, including APK results, through DocumentsUI without the invalid URI grant. It opens the folder, installs nothing, and changes no package handler or default app.

Why is a package marked External?

It was disabled before EvoX Quick Fix owned it. The restore action will not enable it.

Why is Circle available without Quick Search or Vector?

Circle checks Launcher3, Google contextual search, the system service and KernelSU independently. It checks Magic Mount-rs only when a systemless feature declaration is needed.

Is LE Audio included in “Apply the four fixes”?

No. LE Audio 1.2 has separate apply and disable controls, accepts only the exact tested SM-S918B/ROM configuration, and requires a manual reboot after either action.

What does OneBack change?

With HeliBoard visible on Android 16, the first Back reaches the foreground app so it can perform its normal navigation rather than HeliBoard consuming it only to hide the IME. The regular hide-keyboard button still hides it. OneBack is scoped only to HeliBoard through Vector/libxposed API 102; it does not hook system_server or inject a synthetic Back.

Can I leave the standalone OneBack module enabled?

No. Disable dev.oneback.ime before enabling the integrated v1.3.0-beta.1 feature to avoid hooking HeliBoard twice.

الشفافية وHookا Quick Search مقفلة على بيئة SM-S918B ونسخة Quick Search المطابقتين. يصلح Hook المجلد محاولات Quick Search لفتح مجلدات التخزين الخارجي المحتوية، ومنها نتائج APK، عبر DocumentsUI دون تغيير أي Handler مسجل أو تطبيق افتراضي. Circle مستقل ويتطلب Launcher3 ومزود Google وخدمة contextual_search وKernelSU؛ ويُطلب Magic Mount-rs فقط إذا كان تعريف الميزة مفقودًا من الروم.

يُقفل LE Audio 1.2 على SM-S918B وAndroid 16 والمستخدم الأساسي وKernelSU وبصمات ملفات سياسة الصوت وBluetooth المختبرة. يعيد تشغيل LC3 ومايك السماعة معًا في الروم المطابق؛ نجاحه هناك لا يثبت إصلاح كل روم أو جهاز أو تطبيق.

OneBack في v1.3.0-beta.1 هو Hook اختياري عبر Vector / libxposed API 102، ونطاقه HeliBoard فقط على Android 16. يعمل داخل HeliBoard لا داخل system_server، ولا يولّد ضغطة Back اصطناعية. قد يختلف تعامل التطبيقات مع Back، لذلك لا يُعد هذا ادعاء توافق عام مع كل تطبيق.

طريقة الاستخدام الآمنة

  1. تحقق من SHA-256 وثبت APK الموقع.
  2. اقرأ شاشة البداية وHelp، ولا تمنح Root إلا بعد تطابق الفحص.
  3. طبق خيارًا واحدًا كل مرة. ينقلك Hookا Quick Search إلى Home عمدًا أثناء إعادة تشغيل Quick Search؛ هذا ليس crash.
  4. قبل تفعيل OneBack المدمج، عطّل الوحدة المستقلة dev.oneback.ime لتجنب Hook مزدوج. استخدم زري التفعيل والتعطيل والاختبار الداخلي الخاص بـOneBack.
  5. للدبلوت: خمس حزم عادية كحد أقصى، أو حزمة خطرة واحدة مع كتابة Package ID.
  6. اختبر المكالمات والرسائل والبيانات والواي فاي والبلوتوث والكاميرا والبصمة والمنبه والإشعارات وRecents وCircle. وإذا فعّلتهما، اختبر تشغيل LE Audio ومايك السماعة واختبار OneBack الداخلي.

الاسترجاع

استرجاع الإصلاحات الأساسية وLE Audio وأزرار OneBack واسترجاع الدبلوت مستقلة عن بعضها. لا يدخل LE Audio أو OneBack ضمن «الإصلاحات الأربعة». لا يعطل «استرجاع وضع الروم» OneBack؛ زر تعطيله الخاص يزيل نطاق HeliBoard لهذه الوحدة فقط ويبقي نطاق Quick Search. لـLE Audio أيضًا زر تعطيل مستقل ويتطلب إعادة تشغيل يدوية. يعيد الدبلوت فقط الحزم التي يملكها Ledger إلى حالتها الأصلية 0..4.

adb shell su -c 'sh /data/adb/evox-quick-fix/debloat-restore.sh'

تعطيل وحدات الإصلاح وقت الطوارئ:

adb shell su -c 'touch /data/adb/modules/evox_contextual_search_fix/disable; touch /data/adb/modules/evox_overview_transparency/disable; reboot'

أسئلة شائعة

هل تثبيت beta يعطل 104 حزم؟

لا. التحديد يبدأ فارغًا وكل حزمة تظهر Keep حتى تختارها بنفسك.

لماذا نقلني التطبيق إلى Home؟

يحتاج Hookا Quick Search إلى إعادة تشغيل Quick Search. تحفظ الأداة العملية أولًا؛ افتحها مجددًا لرؤية النتيجة وطلب Restart.

هل يثبت إصلاح نتائج APK الملفات تلقائيًا؟

لا. في نسخة Quick Search المطابقة يصلح فتح مجلدات التخزين الخارجي المحتوية، ومنها نتائج APK، عبر DocumentsUI دون URI grant غير الصالح. يفتح المجلد ولا يثبت شيئًا ولا يغيّر Handler الحزم أو التطبيق الافتراضي.

لماذا تظهر حزمة External؟

كانت معطلة قبل أن تملكها الأداة، ولذلك لن يقوم الاسترجاع بتفعيلها.

لماذا Circle مستقل عن Quick Search وVector؟

يفحص Circle ‏Launcher3 ومزود Google وخدمة النظام وKernelSU بصورة مستقلة، ولا يفحص Magic Mount-rs إلا عند الحاجة لإضافة تعريف الميزة systemless.

هل يدخل LE Audio ضمن «الإصلاحات الأربعة»؟

لا. لـLE Audio 1.2 زرا تطبيق وتعطيل مستقلان، ولا يقبل إلا إعداد SM-S918B والروم المختبر المطابق، ويتطلب إعادة تشغيل يدوية بعد كلتا العمليتين.

ماذا يغيّر OneBack؟

عند ظهور HeliBoard على Android 16، يصل أول Back إلى التطبيق الأمامي كي ينفذ تنقله المعتاد بدل أن يستهلكه HeliBoard لإخفاء الكيبورد فقط. يبقى زر إخفاء الكيبورد الطبيعي فعالًا. نطاق OneBack هو HeliBoard فقط عبر Vector / libxposed API 102؛ لا يستخدم system_server ولا يحقن Back اصطناعيًا.

هل أترك وحدة OneBack المستقلة مفعلة؟

لا. عطّل dev.oneback.ime قبل تفعيل ميزة v1.3.0-beta.1 المدمجة لتجنب Hook مزدوج داخل HeliBoard.
